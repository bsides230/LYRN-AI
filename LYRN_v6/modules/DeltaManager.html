Delta Working Memory Guide

Delta Working Memory (Layer 2) provides dynamic operational state between the static Layer 1 base snapshot and the Layer 3 job execution context.

  • KV Cache Prefix Hit: Layer 1 remains completely unmodified at prompt index 0. Layer 2 is injected as prompt index 1, strictly preserving 100% prefix match hit performance.
  • Delta RWI: The compiler automatically generates a Relational Web Index header listing all active delta modules in configured order.
  • Programmatic Updates: Automated jobs update delta source files on disk via POST /api/deltas/update.
  • Code-Defined Modules: Modules are registered via deltas/delta_config.json with modular sources in deltas/sources/.
